# Interactive Tree Editor

A JavaFX coursework project by Davis Ernst at the University of Saskatchewan. The editor separates its tree model, interaction state, controller, detail view, and overview, using publish-subscribe updates to keep both views synchronized.

Source is under `A4/src/main/java/com/example/a4/`. The Maven project targets Java 25 and uses JavaFX 21.0.6. `EditorApp` is the tree editor entry point; the repository also retains the original JavaFX starter classes.
